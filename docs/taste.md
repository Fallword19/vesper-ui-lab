# Vesper 审美记录

从问卷和看图速配里整理出来的口味，后面做新页面时先看这里。

## 喜欢什么

- **看图速配**：喜欢「无印」「粗野主义」；还行「工业仪器」「终端」「黑金」「北欧」。
- **不喜欢**：圆环图、玻璃拟态、霓虹、粉彩、手账、胶片、中式、像素、单个巨大数字、杂志排版。
- **共同点**：平，不装饰，结构靠线和框，像一件用得住的工具。凡是「在表演氛围」的都不要。
- **问卷**：清晨薄雾（白天偏冷）、通透明亮、空无一物、宋体书信感、微动、安静地陪着；夜里想要烛光暖暗。

## 已定的

- **聊天页**：保持现状。气泡圆角 18pt 连续圆角、无尾巴、内边距 14/8、最大宽度 76%、正文 12.5pt、行距 1.8、时间 8.5pt、两侧 12pt、同侧间距 9、换人间距 18。往上面硬加锋利元素反而更差。
- **气泡详情页**：用「无印」，代码见 `swiftui/MujiDetailView.swift`。
- **以后**：单独做一套粗野主义主题（详情页草稿 J-2：米灰底、1.5pt 黑框、实心黑条、4pt 硬阴影、本轮变化用黄色 #FFD400）。

## 无印的规则

| 用途 | 浅色 | 深色 |
|---|---|---|
| 底色 | #F2EEE6 | #1D1B18 |
| 正文 | #3B3530 | #E8E2D8 |
| 次要文字 | #756C62 | #A39A8E |
| 细线 | #D9D0C3 | #36322D |
| 强调（大变化） | #8C2F24 | #C0584A |

- 左右留白 28pt，分区标签 10pt、字距 3pt。
- 数字、时间、模型名都用等宽字体。
- 读到的那句话用宋体 17pt，行距大。
- 变化绝对值 ≥ 3 才用强调色，其余变灰。
- 条长按真实比例（0–100），不要把小变化画得和大变化一样长。
